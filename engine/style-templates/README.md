# Style templates

Reusable, generic HyperFrames scene templates live here. Copy a template into an ignored video project, replace
its placeholder media and text, then apply the active client style. Templates are starting points, not approved
brand packages; verify typography, safe areas, timing, and contrast in the rendered output.

Each template keeps its own `AGENTS.md`, `meta.json`, and `hyperframes.json` where needed. Client-specific style
packages belong under `styles/clients/<slug>/`; the fictional Ember Coffee example shows the expected structure.
