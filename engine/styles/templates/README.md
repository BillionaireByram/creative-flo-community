# Style Studio templates

These generic starter styles are seeded into Style Studio. Each folder contains `template.json`, `style.json`,
and `DESIGN.md`; its stable folder name is the template key. The fictional examples contain no client assets.

Run the validator after editing a template:

```sh
cd engine
python3 styles/templates/check_templates.py
```

Names must be descriptive, fonts must be redistributable, and sample claims must be obvious placeholders. A
template should state its format, signature pieces, restrained uses, prohibited choices, rhythm, sound, and end tag.
